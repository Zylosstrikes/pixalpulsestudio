App icons
=========

AnimeSoul
  Replace this one file to update the AnimeSoul icon in the store:
    icons/apps/animesoul.png

  Use a 512×512 PNG. A rounded square (squircle) matches the other app icons.

Nova Linx icons are copied from the live product, with a small badge
on the Android, API, and Nova Code variants so they
are easy to tell apart in the catalog.
